# Md Shahabuddin — Portfolio

React + Vite + Tailwind CSS v4. Geist / Geist Mono, zinc palette, single-column layout.

```bash
npm install
npm run dev      # local dev server
npm run build    # production build in dist/
```

- All content lives in `src/data.js`.
- GitHub username is set in `GITHUB_USER`; the activity grid, followers and repo count load live from GitHub.
- The avatar uses your GitHub photo. To use your own, add `public/avatar.jpg` and set `avatar: '/avatar.jpg'` in `src/data.js`.
